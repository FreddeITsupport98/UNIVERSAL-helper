- [2026-04-29 19:30 UTC] Fixed false-positive `Downloader prefetch error / Status: error:solver:1 / Detail: Solver/download error (rc=1) / Incident: inc-downloader-solver-1` notification spam on Fedora hosts that have a pending distro-upgrade staged. Fixes shipped: (1) the deployed `zypper-autodownload.service` unit and the verify auto-repair `Check 10c` rewrite now include `-/usr/lib/sysimage/libdnf5 -/usr/lib/sysimage/libdnf5/offline` in `ReadWritePaths=` (with the `-` optional-path prefix per `systemd.exec(5)` so non-dnf5 hosts still start cleanly). The auto-repair trigger pattern now ALSO fires when the existing `ReadWritePaths=` is missing the libdnf5 staging dirs entirely, so users on prior builds self-heal at the next `--verify` run. (5) Added focused static regression `regressions/test_downloader_prefetch_error_classification_regression.sh` that asserts helper presence, libdnf5 paths in both the deployed unit and the auto-repair `dl_expected_rw`, auto-repair trigger fires on missing-libdnf5, all three failure paths route through the classifier instead of writing `error:solver:$RC` directly, and the prefetch helper's err_file passthrough wiring is intact.
