Added a single source-of-truth Python helper `_conflict_guidance(pm, surface, conflict_summary=...)` plus new endpoint `GET /api/system/conflict-guidance` returning `package_manager` / `surface` / `headline` / `explanation` / `recommended_cmd` / `refresh_cmd` / `terminal_only` / `solver_choices` / `steps` / `manager_hint`.
